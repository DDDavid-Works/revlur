How to blur everything except one part of a web page

November 8, 2026 · David

Sometimes you want people to see one part of a page and nothing else. Hiding the rest completely loses context; blurring it keeps the shape of the page while taking the detail away.

When this is useful

  • Presenting: keep a meeting on one chart instead of the whole dashboard.
  • Teaching: walk students through a page one section at a time.
  • Screen sharing: keep side content, like other people's names or numbers, out of focus.
  • Reading: keep only the paragraph you're on sharp. See reading long articles without distractions.

Without installing anything: developer tools

If you're comfortable with Chrome's developer tools, you can add a CSS blur to the elements you want hidden. Right-click an element, choose Inspect, and add filter: blur(8px) to its styles. Repeat for each part of the page you want blurred.

It works, but it's slow: pages are built from many nested elements, so blurring “everything except this box” usually means blurring a dozen elements one by one. The changes vanish when you reload, and it's not something you'd do live in front of an audience.

For a still image: blur in a screenshot editor

If you only need a picture, take a screenshot and use the blur or pixelate tool in an image editor to blur everything except your area. That's fine for documentation, but it isn't live: you can't scroll, click or change the selection without starting over.

Live, on any page: Revlur

Revlur is a free Chrome extension built for exactly this. It works on the live page, in a few seconds:

  1. Click the Revlur icon in the toolbar. (Pin it from the puzzle-piece menu so it's always visible, or set a keyboard shortcut at chrome://extensions/shortcuts.)
  2. Drag a box around the part you want to keep. Everything else gets blurred.
  3. Adjust the blur from 0 to 20 pixels with the slider. Revlur remembers your setting.
  4. Drag the red corner brackets or edges to fine-tune the area, or press Re-select to pick a new one.
  5. Press Esc when you're done. The page is left exactly as it was.

Revlur never changes the page itself; it only draws on top of it. It has no account, sends nothing anywhere, and only runs on the page you click it on.

Good to know

Chrome doesn't let extensions run on its own pages (like chrome:// settings), the Chrome Web Store or its built-in PDF viewer, so Revlur won't start there. It follows the main page scroll; panels that scroll on their own inside a page aren't tracked.
